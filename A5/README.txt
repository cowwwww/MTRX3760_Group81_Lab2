A5 - Noise Bonus

This is a copy of A2 augmented with:
- random x/y and heading offsets at construction,
- a small random offset to each wheel's travel distance on every update,
- 20 wall followers and 20 line followers in one simulation.

Build with raylib as for A2. The random seed is fixed so the result is
repeatable while still showing a spread of trajectories.
